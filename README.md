# GeneratorSTM32

Двухканальный генератор прямоугольных импульсов на STM32F103C8T6. Заменяет громоздкий советский генератор импульсов, который давал сильные помехи по земле и требовал дорогостоящего ремонта.

## Функционал

- Генерация прямоугольных импульсов длительностью единицы микросекунд на низких частотах (100 Гц — 1 кГц)
- Настраиваемые параметры: частота, период между импульсами, длительность импульсов
- Отображение параметров на дисплее ST7789
- Сохранение настроек в EEPROM

## Назначение

Генератор предназначен для настройки контрольно-измерительной аппаратуры. Прежде для этого использовался большой советский генератор импульсов, который давал значительные помехи по земле и часто выходил из строя.

## Аппаратная часть

- MCU: STM32F103C8T6
- Дисплей: ST7789 (SPI)
- EEPROM для хранения настроек
- Плата спаяна вручную на макетной плате

## Стек

C, STM32F103, CMSIS/HAL, таймеры, SPI (дисплей), I2C (EEPROM)

## Сборка

Проект собирается в STM32CubeIDE.
